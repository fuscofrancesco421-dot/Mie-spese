# BudgetFlow PRO v2

Versione avanzata del gestore spese.

## Nuove funzioni
- Dashboard stile app finanziaria
- Dark mode
- Budget per categoria con barra di avanzamento
- Obiettivi di risparmio
- Spese ricorrenti
- Analisi automatica personalizzata
- Indicatori finanziari
- Grafico andamento del saldo
- Alert quando superi un budget
- Profilo con reddito, obiettivo e strategia
- Login e database Supabase
- Responsive per iPhone

## Configurazione
1. Crea un progetto Supabase.
2. Vai in SQL Editor e incolla `supabase.sql`.
3. Copia Project URL e anon/public key.
4. Inseriscili nelle prime righe di `app.js`.
5. Avvia la cartella con un server locale, ad esempio `python -m http.server 5500`.
6. Apri `http://localhost:5500`.

Non inserire mai una Supabase service-role key nel browser.
